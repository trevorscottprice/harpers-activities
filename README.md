# Harper's Activities

A small PWA that helps a tween get ready for activities and leave on time. It's plain HTML/CSS/JS with no build step, and all data is stored on the device.

## Run locally
    python -m http.server 8000      # then open http://localhost:8000

## Put it on an iPhone
1. Host the folder over HTTPS (for example GitHub Pages: push the repo, then Settings → Pages → deploy from `main` / root).
2. Open the URL in Safari, tap Share, then **Add to Home Screen**.

When you change any file, bump `VERSION` in `sw.js` so installed copies pick up the update.
Icons are generated by `python make_icons.py` (needs Pillow).
