# Harper's Activities

A small PWA that helps a tween get ready for activities and leave on time. It's plain HTML/CSS/JS with no build step, and all data is stored on the device.

Live: https://trevorscottprice.github.io/harpers-activities/

## Install on an iPhone
Open the link above in **Safari**, tap **Share**, then **Add to Home Screen**.

## Run locally
    python -m http.server 8000      # then open http://localhost:8000

## Ship a change
1. Bump `VERSION` in `sw.js`. Installed copies only pick up new files when it changes.
2. Commit and push to `main`. GitHub Pages redeploys in about a minute.
3. On the phone, close and reopen the app (sometimes twice) to load the new version.

Icons are generated by `python make_icons.py` (needs Pillow).
